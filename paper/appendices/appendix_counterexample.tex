\section{Proof of \cref{lem:no_spectral_stability}}
\label{app:no_spectral_stability}

Let $\mathbf{1}_B$ denote the indicator function of a measurable set $B\subset\bT^d$. Let $\bI\in\cV^4$ denote the identity operator on $\cV^2$. Let $\mathrm{Id}_{\cX}$ denote the identity operator on $\cX$. For $m\in\bN$, define $B_m\coloneqq \{y\in\bT^d\simeq [0,1)^d\mid 0< y_1<1/m\}$, where $a_m\coloneqq \mathbf{1}_{B_m}$.
Then $\mu(B_m)=1/m$, $\mathbf{1}_{B_m}$ has total variation of $2$, and $a_m$ is uniformly bounded in $\mathrm{BV}(\bT^d)$. Set $\bV_m\equiv \bV\equiv \bE \equiv \bI$ and $\bE_m\coloneqq (1+a_m)\bI$. Since $1\le 1+a_m\le 2$ and $a_m$ is uniformly bounded in $\mathrm{BV}$, we have $(\bV_m,\bE_m)\in\cM$ for all $m$. Moreover, $\|\bV_m-\bV\|_{L^1_{\rm per}}=0$ and $\|\bE_m-\bE\|_{L^1_{\rm per}}=\mu(B_m)\,\|\bI\|_F=m^{-1}\|\bI\|_F\to0$.
Thus $(\bV_m,\bE_m)\to(\bV,\bE)$ in $L^1_{\rm per}$. Since $\bV=\bE=\bI$, we have $\cR_{\bV,\bE}=\mathrm{Id}_{\cX}$. Additionally, For every $\eta\in\cX$, we have $\cR_{\bV_m,\bE_m}\eta=\eta+\cP_{\bI}(M_{a_m}\eta)$, where $(M_{a_m}\eta)[y]\coloneqq a_m(y)\eta(y)$ is a pointwise multiplication operator.

Choose a non-constant function $\psi_m\in C^\infty(\bT^d)$ with $\operatorname{supp}(\psi_m)\subset B_m$, and fix a nonzero direction $y_*\in\bR^d$. Set $\varphi_m\coloneqq \psi_m y_*$ and $\eta_m\coloneqq \mathrm{sym}(\nabla_y\varphi_m)$. Then $\eta_m$ is nonzero and supported in $B_m$. Let $\widetilde\varphi_m\coloneqq \varphi_m-\int_{\bT^d}\varphi_m\,\mathrm{d}y\in \mathring{H}^1_{\rm per}(\bT^d;\bR^d)$. Since $\nabla_y\widetilde\varphi_m=\nabla_y\varphi_m$, we have $\eta_m=\mathrm{sym}(\nabla_y\widetilde\varphi_m)\in\cX$. Normalize $\widehat\eta_m\coloneqq \eta_m/\|\eta_m\|_{L^2_{\rm per}}\in\cX$. Since $\mathrm{supp}(\widehat\eta_m)\subset B_m$, we have $a_m\widehat\eta_m=\widehat\eta_m$ a.e., and we have $\cR_{\bV_m,\bE_m}\widehat\eta_m
=2\widehat\eta_m$. Thus $2$ belongs to the spectrum of $\cR_{\bV_m,\bE_m}$ for every $m\in\bN$, and $\Lambda_+(\bV_m,\bE_m)\ge 2$. Conversely, 
$(\cR_{\bV_m,\bE_m}\eta,\eta)_{L^2_{\rm per}}
=(\eta,\eta)_{\bE_m}
=\int_{\bT^d}(1+a_m(y))\|\eta(y)\|_F^2\,\mathrm{d}y
\le 2\|\eta\|_{L^2_{\rm per}}^2$ for all $\eta\in\cX$, so $\cR_{\bV_m,\bE_m}$ satisfies $\Lambda_+(\bV_m,\bE_m)\le 2$.
Therefore $\Lambda_+(\bV_m,\bE_m)=2$ for all $m\in\bN$.
